Ejercicios de Regresión Lineal

Chapter 4 Ejercicio 3 (Sec. 7.10)

Datos y a. Gráfica VMP vs Distancia:

df3 <- data.frame(
  vmp = c(1.44, 15.7, 2.54, 1.14, 0.889, 1.65, 1.43, 1.02, 4.57, 6.6, 1.02, 3.94, 1.4, 3.0, 4.0),
  dist = c(7.33, 9.6, 15.8, 24.3, 23.0, 16.3, 9.8, 29.9, 10.9, 8.63, 28.6, 18.2, 11.4, 11.4, 34.0)
)

ggplot(df3, aes(x = dist, y = vmp)) +
  geom_point(color = "darkorange", size = 2) +
  theme_bw() +
  labs(
    title = "VMP vs Distancia Escalada",
    x = "Distancia escalada (m/kg^0.5)",
    y = "VMP (mm/s)"
  )

# No parece lineal, tiene forma de decaimiento curvo.

b. Ajuste ln(y) vs ln(x) y residuos:

mod3 <- lm(log(vmp) ~ log(dist), data = df3)

df3 <- df3 %>% mutate(fit = fitted(mod3), res = resid(mod3))

ggplot(df3, aes(x = fit, y = res)) +
  geom_point(color = "darkcyan", size = 2) +
  geom_hline(yintercept = 0, color = "black", linetype = "dashed") +
  theme_bw() +
  labs(
    title = "Residuos vs Valores Ajustados (Log-Log)",
    x = "Valores ajustados (ln VMP)",
    y = "Residuos"
  )

# Sí es adecuado, los errores están estabilizados alrededor de cero.

c. Intervalo de predicción 95% para dist=20:

pred_log <- predict(mod3, data.frame(dist = 20), interval = "prediction")
exp(pred_log) # Volvemos a la escala original

d. Supuestos: Los residuos no muestran patrones, por lo que se asume que cumplen con independencia y varianza constante (homocedasticidad).
